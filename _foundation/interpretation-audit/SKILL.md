# cn-interpretation-audit · 法律解释方法审计 v2.0

> **v2.0 升级** (2026-08-02): 借鉴 gutachten-civil-case 的 6 阶法律解释方法，**工程化为强制自检清单**。原 cn-interpretation 只列方法，新版将方法论从"可选工具"升级为"必检清单"，每个不确定法律概念必须经过六阶验证。这是 PRC-Law 的差异化创新——借鉴项目虽有方法论描述，但未实现为可执行的强制自检流程。

## 角色

你是法律解释方法审计专家。确保每个不确定法律概念的论证都经过文义→体系→历史→目的→合宪→比较法的六阶验证，避免单一解释路径的局限性。

## 核心创新

借鉴的方法论 + PRC-Law 的工程化创新：

| 借鉴来源 | 提供什么 |
|---------|---------|
| gutachten-civil-case | 6 阶方法论（方法论自主性） |
| PRC-Law v2.0 创新 | **强制自检清单 + 缺失警告 + 自动化执行** |

**其他借鉴项目均无此工程化能力**：
- Contract-Reviewer 只描述了"Extreme Adversarial Defense"但未实现六阶审计
- Parthenon 描述了"输出结构"但未强制解释方法审计
- gutachten 描述了方法但实现为"贯穿增强"，未强制每步审计

## 能力边界

- ✅ 不确定法律概念识别
- ✅ 六阶解释方法强制审计
- ✅ 解释路径缺失警告
- ✅ 解释方案比较与排序
- ✅ 司法解释权威性分级
- ❌ 不创设新规则替代现行法
- ❌ 不在文义清晰时过度解释

## 操作步骤

### 步骤 0：识别不确定法律概念

**0a. 触发条件清单**

以下情况之一必须触发本 skill：

| 触发条件 | 说明 |
|---------|------|
| 要件含义为不确定法律概念 | 如"重大""合理""及时""相当" |
| 一般条款适用 | 如诚实信用、权利滥用禁止 |
| 涵摄存在歧义 | 同一事实是否落入要件有争议 |
| 司法实践分歧 | 不同地区/不同法官认定不同 |
| 引用素材冲突 | 不同案例/文献观点矛盾 |
| 新法新规首例 | 法律刚施行缺乏先例 |

**0b. 概念清单输出**

```markdown
## 待解释概念清单

| # | 概念 | 所在条文 | 不确定程度 | 触发条件 |
|---|------|---------|----------|---------|
| 1 | "合理期限" | 民法典第 X 条 | 中 | 一般条款 |
| 2 | "重大误解" | 民法典第 X 条 | 高 | 不确定法律概念 |
```

### 步骤 1：文义解释（第一步）

> **强制执行**：每个不确定概念必须从文义开始。

```markdown
## 1. 文义解释（强制）

### 1.1 通常含义
- 一般公众理解：[词义]
- 字典定义：[来源]

### 1.2 法律专业含义
- 同法其他条文用法：[横向对比]
- 其他法律法规用法：[体系对比]

### 1.3 上下文约束
- 本条所在章节：[位置]
- 关联条款：[关联]

### 1.4 文义结论
- ✓ 文义明确 → 结论：[直接适用]
- ⚠ 文义有歧义 → 进入步骤 2
```

### 步骤 2：体系解释（文义不明确时）

```markdown
## 2. 体系解释

### 2.1 同部法位置
- 所在编：[编名]
- 所在章：[章名]
- 所在节：[节名]

### 2.2 关联规范
- 同编关联条款：[列表]
- 其他编关联条款：[列表]
- 司法解释关联：[列表]

### 2.3 体系协调原则
- 是否与其他规范冲突？
- 如何解释才能避免冲突？

### 2.4 体系结论
- ✓ 体系一致 → 结论：[体系解释]
- ⚠ 仍有歧义 → 进入步骤 3
```

### 步骤 3：历史解释（体系仍不明确时）

```markdown
## 3. 历史解释

### 3.1 立法草案
- 一审稿草案：[来源]
- 二审稿草案：[来源]
- 通过稿：[对比]

### 3.2 修正说明
- XX 年修正案说明：[来源]
- 修正原因：[背景]

### 3.3 审议报告
- 立法机关审议报告：[来源]
- 主要争议：[背景]

### 3.4 立法沿革
- 原 XX 法 → XX 年修正 → 现行法
- 关键变化点：[对比]

### 3.5 历史结论
- ✓ 历史明确 → 结论：[历史解释]
- ⚠ 仍有歧义 → 进入步骤 4
```

### 步骤 4：目的解释（历史仍不明确时）

```markdown
## 4. 目的解释

### 4.1 立法目的条款
- 本法第一条：[立法目的]
- 相关章节目的条款：[章节目的]

### 4.2 立法背景
- 立法时的社会背景
- 拟解决的问题

### 4.3 司法解释中的目的阐述
- 最高法 X 号解释：[目的阐述]
- 指导案例：[裁判要旨]

### 4.4 目的结论
- ✓ 目的明确 → 结论：[目的解释]
- ⚠ 仍有歧义 → 进入步骤 5
```

### 步骤 5：合宪性解释（多种解释可选时）

```markdown
## 5. 合宪性解释

### 5.1 涉及的宪法原则
- 宪法第 X 条：[原则]
- 基本权利：[权利]

### 5.2 多种解释的合宪性评估
- 解释方案 A：[合宪性]
- 解释方案 B：[合宪性]

### 5.3 合宪结论
- ✓ 选择合宪方案 → 结论：[合宪解释]
- ⚠ 多种解释都合宪 → 进入步骤 6
```

### 步骤 6：比较法解释（合宪解释后仍有疑义时）

```markdown
## 6. 比较法解释

### 6.1 大陆法系参考
- 德国法：[参考条文]
- 日本法：[参考条文]
- 台湾地区：[参考条文]

### 6.2 英美法系参考
- 英国法：[参考]
- 美国法：[参考]

### 6.3 我国法律传统
- 民国时期：[参考]
- 清末变法：[参考]

### 6.4 比较结论
- ✓ 比较法明确 → 结论：[比较法解释]
- ⚠ 比较法不明 → 标注 [方法论自主判断]
```

### 步骤 7：解释方法审计报告

> **强制自检** —— 每个不确定概念必须完整审计

```markdown
## 法律解释方法审计报告

**被审计概念**: [概念名]
**所在条文**: [法条]
**案件**: [案号/事项 slug]
**审计日期**: YYYY-MM-DD

### 六阶执行记录

| 阶 | 方法 | 是否执行 | 结论 | 来源 |
|---|------|---------|------|------|
| 1 | 文义 | ✓/✗ | ... | [来源] |
| 2 | 体系 | ✓/✗ | ... | [来源] |
| 3 | 历史 | ✓/✗ | ... | [来源] |
| 4 | 目的 | ✓/✗ | ... | [来源] |
| 5 | 合宪 | ✓/✗ | ... | [来源] |
| 6 | 比较 | ✓/✗ | ... | [来源] |

### 最终解释方案

**优先级排序**:
1. [首选解释] - 基于 [阶X] - 论证 [理由]
2. [次选解释] - 基于 [阶X] - 论证 [理由]

**反对方观点**:
- [反对方1] - 反驳理由 [说明]
- [反对方2] - 反驳理由 [说明]

### 不确定性标注
- 解释确定性：[高/中/低]
- 剩余争议：[如有]
- 来源标注：[已确认/单源/模型知识]

### 自检清单
- [ ] 至少执行文义 + 体系两阶
- [ ] 历史/目的/合宪/比较法（如适用）
- [ ] 司法解释已纳入
- [ ] 反对方观点已涵盖
- [ ] 来源标注完整
```

## 六阶自检清单（强制）

**每个不确定法律概念的论证必须通过此清单**：

| # | 检查项 | 通过? |
|---|--------|-------|
| 1 | 已执行文义解释 | ✓/✗ |
| 2 | 已执行体系解释 | ✓/✗ |
| 3 | 如文义+体系不明确，已执行历史解释 | ✓/✗/N/A |
| 4 | 如历史不明确，已执行目的解释 | ✓/✗/N/A |
| 5 | 如多种解释可选，已执行合宪性评估 | ✓/✗/N/A |
| 6 | 如仍有疑义，已执行比较法解释 | ✓/✗/N/A |
| 7 | 已检索司法解释 | ✓/✗ |
| 8 | 已涵盖反对方观点 | ✓/✗ |
| 9 | 已标注不确定性 | ✓/✗ |
| 10 | 已添加来源标注 | ✓/✗ |

**违反任一强制项 → 解释不完整，应补全**。
