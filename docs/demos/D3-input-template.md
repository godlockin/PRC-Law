# D3 Demo 输入材料：员工受贿内部调查

> **基于合规热线举报场景的通用模板**
> 数据来源：合规管理最佳实践（公开案例脱敏）
> 用户需根据实际举报材料调整

---

## 举报基本信息

```
举报日期：YYYY-MM-DD
举报渠道：合规热线 / 邮件 / 现场
举报人：匿名 / 实名
被举报人：[员工姓名]，[职位]，[所属部门]
涉嫌行为：[具体行为描述]
```

---

## 举报内容示例

```markdown
举报人：匿名（合规热线 #2026-XXX）

被举报人：销售部高级经理 王某某

涉嫌行为：
- 2025 年 6 月至 2026 年 5 月期间
- 收受 A 供应商 30 万元、B 供应商 20 万元
- 行为方式：合同审批时倾向特定供应商，私下收受回扣
- 涉及合同金额合计约 500 万元

可能涉及罪名：
- 非国家工作人员受贿罪（刑法第 163 条）
- 职务侵占罪（刑法第 271 条）
```

## 调查流程

按律鉴 `cn-internal-investigation` 自动编排：

1. **案件评估**（0-2 小时）
   - 举报材料初步审查
   - 评估严重程度（高/中/低）
   - 决定是否启动正式调查

2. **证据保全**（2-24 小时）
   - 财务凭证冻结
   - 电子证据公证
   - 涉事人员访谈

3. **证据评估**（1-3 天）
   - 三性审查（真实性/合法性/关联性）
   - 证明力分级
   - 证据链闭环分析

4. **法律后果评估**（1-3 天）
   - 涉嫌罪名分析（刑法第 163 条）
   - 公司内部处分依据（《员工手册》第 X 条）
   - 民事赔偿（损失追偿）

5. **处置建议**（3-7 天）
   - 立即停职
   - 启动正式调查
   - 同步报案
   - 民事追偿

6. **后续整改**（持续）
   - 制度漏洞修补
   - 流程优化
   - 培训宣导

## 律鉴编排链路

```
用户输入: "收到员工受贿举报，请按内部调查流程处理"
↓
自动触发 cn-internal-investigation:
  - 案件评估
  - 证据评估（cn-evidence-evaluation）
  - 法律后果（cn-consequence-conflict）
  - 风险矩阵（cn-systematic-risk）
  - 处置建议
↓
输出完整调查报告
```

预计时间：3-5 分钟（案件评估阶段）+ 持续调查
预计 API 调用：5-8 次（评估阶段）

## 关联能力

- `cn-internal-investigation` 内部调查全流程
- `cn-evidence-evaluation` 证据三性+证明力
- `cn-statute-watchdog` 监测刑法第 163 条最新司法解释
- `cn-systematic-risk` 法律×商业×声誉 跨领域风险
- `cn-crisis-response` 重大案件的危机响应
