## D5 Demo 输入材料：数据泄露响应

> **基于公开数据泄露事件改编**
> 数据来源：通用应急响应模板

---

## 事件基本信息

```markdown
事件名称：用户数据库疑似泄露
事件级别：🔴 P0 紧急
发现时间：YYYY-MM-DD HH:MM
发现途径：[外部报告 / 内部监控 / 暗网监测]

影响范围：
- 用户数：约 50 万
- 数据类型：姓名、电话、邮箱、地址
- 是否含敏感信息：[身份证/银行卡/密码] 是/否

初步调查：
- 攻击向量：第三方供应商漏洞
- 是否已修复：[是/否]
- 是否通知监管：[是/否]
```

---

## 响应时间表（参考 PIPL 第 57 条）

```
0-2 小时：
- 应急小组组建
- 立即启动证据保全
- 初步技术调查

2-6 小时：
- 详细技术调查
- 评估影响范围
- 准备监管报告

6-24 小时：
- 向网信办报告
- 向公安部报告（如涉及网络安全）
- 用户通知（如需）
```

---

## 调用律鉴能力

```
用户输入: "发现数据泄露事件，请启动应急响应"
↓
自动触发:
  1. cn-crisis-response（P0 应急流程）
  2. cn-data-breach-response（数据泄露专项）
  3. cn-PIA（个人信息保护影响评估）
  4. cn-statute-watchdog（PIPL 法规监测）
  5. cn-systematic-risk（跨领域风险矩阵）
↓
输出完整应急响应报告
```
