## 合同文本

```markdown
# SaaS 服务采购协议

**合同编号**: SAAS-2026-XXXX
**甲方**（采购方）: [甲方公司名称]
**乙方**（服务方）: [乙方云服务公司名称]

## 第一条 服务范围

乙方为甲方提供云计算资源服务，包括但不限于：
- 计算资源（云服务器、容器服务）
- 存储资源（对象存储、块存储）
- 网络资源（CDN、负载均衡）
- 数据库托管（RDS、Redis、Elasticsearch）

## 第二条 服务级别（SLA）

| 服务类型 | 可用性 | 不可用赔偿 |
|---------|--------|------------|
| 计算资源 | 99.95% | 服务费 10% / 月 |
| 存储资源 | 99.99% | 服务费 25% / 月 |
| 数据库 | 99.95% | 服务费 15% / 月 |

## 第三条 费用

年费 ¥500 万元，按季度支付（每季度 ¥125 万）。

## 第四条 数据安全

- 乙方应通过 ISO 27001、SOC 2 Type II 认证
- 数据传输 TLS 1.2+ 加密
- 数据存储 AES-256 加密
- 每日异地备份

## 第五条 责任限制

乙方对甲方的总责任不超过甲方在责任发生前 12 个月已支付的服务费总额。

## 第六条 终止

- 任何一方可提前 30 天书面通知终止
- 违约金：未履行期间服务费的 50%
- 数据迁移期：合同终止后 90 天

## 第七条 争议解决

本协议适用中华人民共和国法律。
争议提交 [XX 仲裁委员会] 仲裁。

## 第八条 其他

- 不可抗力：按民法典第 590 条处理
- 通知：电子邮件 + 纸质
- 转让：需对方书面同意
```

## 待审查问题清单

### 商业条款
1. SLA 99.95% 不可用赔偿是否足够？
2. 数据迁移 90 天是否充分？
3. 责任限制 12 个月服务费是否合理？

### 法律条款
4. 仲裁条款的可执行性？
5. 不可抗力条款是否过于严格？
6. 违约金 50% 是否过高？

### 业务条款
7. 转让条款是否限制业务发展？
8. 数据安全条款是否足够具体？

## 期望产出（律鉴自动编排）

1. **审查摘要**：3-5 条关键发现 + 总体风险评级
2. **5 维评分卡**：合规 30% / 财务 25% / 防御 20% / 履行 15% / 商业 10%
3. **6-Agent 详细发现**：
   - 合规：仲裁条款、不可抗力、转让限制
   - 财务：责任限制 + SLA 赔偿 vs 潜在损失
   - 攻防：替代条款（数据迁移期、责任上限）
   - 生命周期：付款节奏、续约、数据迁移节点
   - 商业：违约金比例、市场惯例对比
   - 校对：条款交叉引用、术语一致性
4. **Agent 质量审计**：4 维（准确性/覆盖度/逻辑性/可执行性）
5. **风险矩阵**：法律×商业 双维度
6. **修订建议**：必须改 / 强烈争取 / 可选改
