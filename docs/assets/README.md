## 使用方式

### GitHub README 头部

```markdown
![律鉴 Logo](docs/assets/logo.svg)
```

### GitHub 仓库封面

GitHub 仓库 → Settings → Social preview → 上传 `banner.svg`

### 文档标题装饰

```markdown
![律鉴 Banner](docs/assets/banner.svg)
```

## 字体说明

SVG 使用 `font-family="SimSun, serif"` — 在中文环境（Windows/macOS/部分 Linux）下会自动使用宋体渲染。如需在 Linux 部署，可安装 `wqy-microhei` 或 `noto-cjk` 字体。

## 设计原则

1. **专业感优先** — 法律行业用户对视觉专业性敏感
2. **金色 + 深色** — 法律权威感的经典配色
3. **天平图标** — 全世界法律行业的通用符号
4. **中英双语** — 兼顾中国律师 + 国际开源社区
5. **零外部依赖** — 纯 SVG，无字体文件、无图片资源
