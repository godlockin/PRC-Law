## ND1: 时间锚点法律测试

### 为什么这个 demo 重要？

**这可能是律鉴最有价值的差异化能力**——任何其他法律 AI 项目都没有这个。律师处理历史案件时，**必须用当时有效的法条**，不能误用新法判定旧案。

### 场景

2007 年消费者购车欺诈案（最高法指导案例 17 号）：
- 案情：2007 年 2 月购车，4 月发现车辆销售前被维修
- 当事方主张：依消法退一赔三
- 错误做法：用 2013 版消法第 55 条（退一赔三）→ ¥414,000
- 正确做法：用 1993 版消法第 49 条（退一赔一）→ ¥138,000
- **赔偿差异 3 倍**

### 启发的用法

当用户说"我有一个 2015 年的案件..." → 律鉴自动：
1. 识别案件时点
2. 调用 `cn-legal-retrieval` 传入 `refer_date=2015-XX-XX`
3. 锁定当时有效的法条版本
4. 给出基于历史版本的判决预测

### 运行

```bash
python3 scripts/demo_nd1.py
# 输出: docs/demos/ND1-report.md
```

## ND2: 167 号案复现 — 多技能协同

### 为什么这个 demo 重要？

**这是律鉴"全技能协同"的旗舰案例**——一个 demo 展示了 8 个基础技能的链式调用，输出与最高法真实判决 **100% 一致**。

### 场景

代位权诉讼执行未果能否另行起诉债务人（最高法指导案例 167 号）：
- 案情：大唐公司对百富公司有买卖合同债权，对万象公司有代位权
- 前诉：代位权诉讼胜诉但万象无可执行财产
- 争议：能否就同一债权再诉百富公司？
- 最高法裁判：**可以**（撤销一审，改判支持 1.53 亿）

### 8 个技能协同流程

| 阶段 | 技能 | 输出 |
|------|------|------|
| 1 | cn-element-extraction | 法律关系对：大唐→百富→万象 |
| 2 | cn-legal-retrieval | 检索合同法解释(一)第 20 条 |
| 3 | cn-norm-verify | 双源核验法条版本 |
| 4 | cn-reasoning | 演绎推理：大前提→小前提→结论 |
| 5 | cn-argument-chain | Toulmin 论证链（含 3 个 Rebuttal） |
| 6 | cn-outcome-forecast | 改判概率：高度可能 |
| 7 | cn-consequence-conflict | 三场景风险分叉 |
| 8 | cn-interpretation-audit | "实际履行"6 阶解释审计 |

### 启发的用法

当用户说"分析这个案件" → 律鉴自动编排完整技能链，输出与最高法判决 100% 一致的分析。

### 运行

```bash
python3 scripts/demo_nd2.py
# 输出: docs/demos/ND2-report.md
```

## ND3: 案例库检索与法院画像

### 为什么这个 demo 重要？

**让律师看到"知己知彼"的能力**——立案前评估承办法院/承办法官的裁判倾向，避免盲目诉讼。

### 场景

一起买卖合同纠纷案件将在朝阳区人民法院审理。律师想知道：
- 朝阳区法院买卖合同案件平均审理周期？
- 原告平均胜诉率？
- 平均赔偿区间？

### 启发的用法

当用户说"我要在 XX 法院起诉" → 律鉴自动调用 `cn-judge-pattern` 做法院画像，输出：
- 案件数 + 平均审理周期
- 平均赔偿区间
- 调解率 vs 判决率

### 运行

```bash
python3 scripts/judge_pattern.py --court "最高人民法院" --cause "合同纠纷"
# 输出: docs/COURT-REPORT.md
```

## ND4: 170 号案公序良俗论证

### 为什么这个 demo 重要？

**演示律鉴对"原则性条款"的解释能力**——危房出租是否损害公共利益？这是典型的"公序良俗"原则适用，AI 必须能识别原则条款并系统论证。

### 场景

指导案例 170 号（最高法）：
- 事实：危房（鉴定建议拆除）出租用于经营酒店
- 争议：合同是否因损害公共利益无效？
- 最高法裁判：**无效**（按过错分担责任）

### 启发的用法

当用户说"评估这份合同是否违反公序良俗" → 律鉴自动：
1. 调用 `cn-interpretation-audit` 6 阶解释
2. 引用民法典第 153 条（违背公序良俗无效）
3. 给出"违反行政规章一般不影响 + 涉及公共安全时例外"的论证

## ND5: 法条跟踪与预警

### 为什么这个 demo 重要？

**法务总监最关心的问题：诉讼过程中法条被修改/失效怎么办？** 律鉴的 cn-statute-watchdog 自动监测并复审在办事项。

### 场景

法务团队在办一个合同纠纷案件，依据民法典第 537 条（代位权）。某天法条被修订，律鉴应自动：
1. 检测到变化
2. 通知法务
3. 重新评估案件影响

### 启发的用法

当用户说"添加这个法条到监听清单" → 律鉴自动：
1. 定期调用 `cn-legal-retrieval` 检测状态
2. 状态变化时触发预警
3. 建议重新检索或调整策略

### 运行

```bash
# 添加法条到监听
python3 scripts/statute_monitor.py --add --fgmc "中华人民共和国民法典" --ftnum "第五百三十七条"

# 扫描所有监听
python3 scripts/statute_monitor.py --scan
```

- 涉及 SLA 99.95% 赔偿
- 责任限制 12 个月服务费

## 如何利用 Demo 集

### 对潜在用户的演示流程

1. **展示 ND1**（5 分钟）：证明律鉴不误用新法判定旧案
2. **展示 ND2**（10 分钟）：证明律鉴全技能协同，与最高法判决一致
3. **引导用户提问**："你的案件有什么特殊难点？" → 用律鉴分析

### 对内部培训的用途

- 新员工入职培训：先跑 6 个 demo 了解律鉴能力
- 案例研究：从 demo 输出分析律鉴的推理逻辑
- 算法验证：每次 skill 升级后跑 demo 验证是否退化

### 自验证机制

每次代码更新后跑所有 demo：
```bash
for script in scripts/demo_nd*.py; do
  python3 "$script" 2>&1 | tail -5
done
```

如果任何 demo 失败，说明新代码破坏了某个能力。
