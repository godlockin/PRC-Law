# 民事起诉状模板

> ⚠️ **律师审阅闸**: 本模板仅提供结构, 具体法条引用/管辖依据/请求金额必须由律师根据案情核实. 起诉前请用 cn-norm-verify 校验所有引用法条现行有效.

## 必填字段 (用 `[占位符]` 标记)

| 字段 | 说明 | 示例 |
|------|------|------|
| `[法院全称]` | 立案管辖法院 | 北京市朝阳区人民法院 |
| `[原告姓名/名称]` | 自然人姓名 或 法人全称 | 张三 / 北京XX科技有限公司 |
| `[原告身份证号/统一社会信用代码]` | 必填 | 1101051980... / 91110105MA... |
| `[原告住所]` | 户籍地/经常居住地/注册地 | 北京市朝阳区... |
| `[原告电话]` | 送达联系方式 | 13800138000 |
| `[被告姓名/名称]` | 同上 | 李四 / 上海XX有限公司 |
| `[被告身份证号/统一信用代码]` | 必填 | ... |
| `[被告住所]` | 同上 | ... |
| `[被告电话]` | 同上 | ... |
| `[案由]` | 最高法《民事案件案由规定》 | 合同纠纷 / 民间借贷纠纷 |
| `[诉讼请求 1, 2, 3...]` | 1-5 项, 编号 | 请求判令被告支付货款200万元 |
| `[事实与理由 段落 1, 2, 3...]` | 时间线 + 法律依据 | 2024-01-15 双方签订合同... |
| `[证据清单]` | 编号 1-10, 简述 + 证明目的 | 证据1: 销售合同, 证明合同关系 |
| `[起诉日期]` | 落款日期 | 2026年9月1日 |

## 正文模板

```markdown

# 民 事 起 诉 状

**[法院全称]**:

## 一、当事人信息

### 原告
- 姓名/名称: [原告姓名/名称]
- 身份证号/统一社会信用代码: [原告身份证号/统一社会信用代码]
- 住所: [原告住所]
- 联系电话: [原告电话]

### 被告
- 姓名/名称: [被告姓名/名称]
- 身份证号/统一社会信用代码: [被告身份证号/统一社会信用代码]
- 住所: [被告住所]
- 联系电话: [被告电话]

(如有多名被告/第三人, 按上述格式继续)

## 二、诉讼请求

1. 请求判令 [诉讼请求 1]
2. 请求判令 [诉讼请求 2]
3. 请求判令 [诉讼请求 3]
4. 本案诉讼费由被告承担

## 三、事实与理由

[事实与理由 段落 1]

[事实与理由 段落 2]

[事实与理由 段落 3]

综上, 被告 [违约/侵权/欠款...] 的行为, 违反了《[XXX 法]》第 [X] 条之规定,
依据《中华人民共和国民事诉讼法》第一百二十一条之规定, 特向贵院提起诉讼,
请求依法判如所请。

## 四、证据清单

| 编号 | 证据名称 | 证明目的 |
|------|---------|---------|
| 1 | [证据1 名称] | [证明目的 1] |
| 2 | [证据2 名称] | [证明目的 2] |
| 3 | [证据3 名称] | [证明目的 3] |
| ... | ... | ... |

此致

**[法院全称]**

具状人: [原告姓名/名称] (签字/盖章)

[起诉日期]

```

## 自动检查清单 (律师提交前)

- [ ] 当事人信息完整 (姓名/身份证号/住所/电话)
- [ ] 诉讼请求具体明确 (金额/行为, 不要抽象描述)
- [ ] 事实时间线完整 (何时/何地/何人/何事/何果)
- [ ] 法律依据现行有效 (用 cn-norm-verify 校验)
- [ ] 管辖正确 (合同履行地/被告住所地/协议管辖)
- [ ] 诉讼费预估 (标的金额 × 适用费率)
- [ ] 证据与请求一一对应
- [ ] 不超过诉讼时效 (民事 3 年, 人身损害 1 年等)

## 关联技能

- `cn-norm-verify` — 校验法律依据现行有效
- `cn-civil-claim-analysis` — 请求权基础鉴定
- `cn-element-extraction` — 从案情描述提取要素
- `cn-evidence-evaluation` — 证据三性审查
- `cn-pleading-defense` — 答辩状 (被告用)
- `cn-pleading-appeal` — 上诉状 (败诉方用)
