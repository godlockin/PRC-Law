# AI 标识 + 律师审阅闸 — 标准片段

> 适用: 所有 cn-pleading-templates 模板顶部 + 末行强制渲染.
> 依据: 上海律协指引 2025-08 §13 + §25 + §30.

## 模板顶部标识 (必填, 不可省略)

```markdown

> ⚠️ **AI 辅助生成 — 律师审阅后使用**
>
> 本文书由 PRC-Law (大模型 + skills 自动加载) 起草, **仅供律师参考**.
>
> 使用前律师必须完成以下核验:
> - [ ] 全部法条引用现行有效 (cn-norm-verify)
> - [ ] 当事人信息完整准确 (身份证号 / 住所 / 电话)
> - [ ] 诉讼请求具体明确 (金额 / 行为)
> - [ ] 事实时间线完整
> - [ ] 管辖正确
> - [ ] 诉讼时效未过期
> - [ ] 证据与请求一一对应
> - [ ] 律师复核签名
>
> 引用来源:
> - 法条: [已确认: 元典法令 + 北大法宝 YYYY-MM-DD]
> - 案例: [本地案例库: <case_id>] 或 [已确认: 元典案例 YYYY-MM-DD]
> - 模板: cn-pleading-templates (https://github.com/godlockin/PRC-Law)

---

[此处放置具体模板正文]

---

```

## 模板末行律师审阅闸 (必填, 不可省略)

```markdown

> ⚠️ **律师审阅闸**: 本文书为 AI 辅助起草, 不构成法律意见.
> 律师必须复核全部内容后亲自签名方可提交法院.
> 最终法律判断由具备执业资格的法律专业人员作出并承担责任.
> PRC-Law 项目地址: https://github.com/godlockin/PRC-Law

具状人/答辩人/上诉人/申请人: [姓名/名称] (签字/盖章)

执业律师: [律师姓名] (签字)

[律所名称] (盖章)

[落款日期]

```

## AI 标识规范要点 (上海律协 §25)

| 要素 | 要求 |
|------|------|
| **角色定位** | 明示这是 AI (而非自然人律师) 生成 |
| **使用范围** | 律师参考 / 律师修改 / 律师签发 |
| **输出体例** | 法律文书 / 合同 / 备忘录 |
| **争议焦点** | 律师专业判断 |
| **地域范围** | 中华人民共和国 |

## 合规边界 (上海律协 §13 + §29)

- ✅ 允许: AI 起草 → 律师复核 → 律师签发
- ⚠️ 谨慎: AI 起草 → 律师**未复核** → 直接提交 (执业风险)
- ❌ 禁止: AI 直接出具"法律意见书" 给当事人 (违反律师法 §14)

## 集成到现有模板

每个 `templates/*.md` 文件顶部应包含:

```markdown
# [文书类型]

> ⚠️ **AI 辅助生成 — 律师审阅后使用** (上海律协指引 §13)
> 使用前律师必须完成以下核验: [见顶部标识]
> 引用来源: PRC-Law v9.0.0 + 本地检索 (日期)

[原有正文内容]
```

模板正文里所有 `[占位符]` 律师填字段时自动消失, AI 标识头保留不变。
