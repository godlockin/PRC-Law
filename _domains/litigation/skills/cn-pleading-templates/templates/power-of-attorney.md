# 民事授权委托书模板 (律师代理用)

> ⚠️ **律师审阅闸**: 授权委托书需明确权限范围 (一般代理 vs 特别代理). 涉及承认/放弃/变更请求等重要权利必须有委托人特别授权.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[委托人]` | 自然人/法人 |
| `[受托人]` | 律师姓名 + 律所名称 |
| `[代理案件]` | 案由 + 对方当事人 |
| `[代理权限]` | 一般代理 或 特别代理 (详细列明) |
| `[代理期限]` | 起诉/审理/执行 各阶段 |
| `[落款日期]` | 委托人签字日 |

## 正文

```markdown

# 民 事 授 权 委 托 书

**委托人 (甲方)**: [委托人姓名/名称]
- 身份证号/统一社会信用代码: [...]
- 住所: [...]
- 联系电话: [...]

**受托人 (乙方)**: [律师姓名], [律所名称] 律师
- 执业证号: [...]
- 律所地址: [...]
- 联系电话: [...]

委托人因 **[案由]** 一案 (对方当事人: [被告姓名/名称]),
现委托上述受托人作为委托代理人, 代为办理下列事宜:

## 一、代理案件

[案由]: [案由]
对方当事人: [被告姓名/名称]
审理法院/仲裁机构: [法院/仲裁委全称]

## 二、代理权限

### 一般代理权限 (《民事诉讼法》第五十九条第一款)

□ 代为提起诉讼/答辩/反诉
□ 代为申请财产保全/证据保全
□ 代为出庭参加庭审, 参与法庭调查/辩论
□ 代为签收法律文书
□ 代为申请回避
□ 代为和解 (无特别授权, 不得单独和解)

### 特别代理权限 (需委托人逐项勾选)

□ 代为承认对方全部或部分诉讼请求
□ 代为放弃、变更诉讼请求
□ 代为进行和解或调解
□ 代为提起反诉或上诉
□ 代为申请执行
□ 代为签署 [具体文书类型, 如: 调解书/和解协议/撤诉申请]
□ 代为 [其他特别事项]

(无上述特别授权的, 受托人无权代为进行上述行为, 委托行为对委托人不发生效力。)

## 三、代理期限

自本委托书签署之日起, 至本案 [起诉/一审/二审/再审/执行] 程序终结之日止。

(可选: 委托期限届满, 委托事项未完成的, 委托人应重新出具委托书。)

## 四、委托人声明

1. 本委托系委托人真实意思表示, 未受胁迫/欺诈
2. 受托人在授权范围内的一切行为, 法律后果由委托人承担
3. 受托人超越授权的行为, 由受托人自行承担责任
4. 委托人变更/撤销委托的, 应及时书面通知受托人

## 五、受托人声明

1. 受托人承诺忠实履行代理职责, 依法维护委托人合法权益
2. 受托人不得超越授权范围行事, 否则承担相应责任
3. 受托人不得泄露委托人在代理过程中知悉的秘密

---

**委托人 (签字/盖章)**: [委托人姓名/名称]

[日期日期]

**受托律师 (签字)**: [律师姓名]

[律所名称] (盖章)

[日期日期]

---

**附: 委托人身份证 / 营业执照 复印件**

```

## 委托权限要点 (律师必读)

### 一般代理 vs 特别代理

| 事项 | 一般代理 | 特别代理 |
|------|---------|---------|
| 起诉/答辩/出庭 | ✅ | - |
| 签收文书 | ✅ | - |
| 财产保全申请 | ✅ | - |
| 和解 | ❌ | ✅ 必需 |
| 承认诉讼请求 | ❌ | ✅ 必需 |
| 撤诉 | ❌ | ✅ 必需 |
| 上诉 | ❌ | ✅ 必需 |

**关键提示**: 无特别授权时, **和解对委托人不生效** (民法典 171 条)。律师代理调解时必须取得明确特别授权, 否则调解结果无效。

## 常见委托类型

1. **民事一审委托** — 起诉/应诉
2. **民事二审委托** — 上诉/被上诉
3. **执行委托** — 申请执行/被申请执行
4. **仲裁委托** — 仲裁申请/应裁
5. **再审委托** — 申请再审/被申请再审
6. **非诉调解委托** — 调解/和解
