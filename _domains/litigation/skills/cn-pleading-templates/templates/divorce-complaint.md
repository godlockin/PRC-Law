# 离婚起诉状模板

> ⚠️ **律师审阅闸**: 离婚案件涉及人身关系, 法院调解是必经程序 (民诉法 122 条). 起诉前应评估调解可能性. 涉及子女抚养/财产分割/债务承担需逐项列明.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[法院]` | 被告住所地基层法院 |
| `[原告/被告]` | 夫妻双方姓名/身份证号 |
| `[结婚日期]` | 结婚登记日 |
| `[子女信息]` | 姓名/出生日期 |
| `[离婚请求]` | 1. 离婚 2. 子女抚养 3. 财产分割 4. 债务承担 |
| `[事实与理由]` | 感情破裂的事由 |
| `[证据]` | 结婚证/子女出生证/财产凭证/聊天记录 |

## 六、感情破裂的法律依据

依据《中华人民共和国民法典》第一千零七十九条, 夫妻感情确已破裂的,
法院调解无效, 应准予离婚。

具体情形 (勾选适用):
□ 重婚或者与他人同居
□ 实施家庭暴力或者虐待、遗弃家庭成员
□ 有赌博、吸毒等恶习屡教不改
□ 因感情不和分居满二年
□ 其他导致夫妻感情破裂的情形 ([具体事由])

## 离婚诉讼特别提示

### 1. 第一次起诉, 法院通常不判离

依据《民法典》§1079 + 最高法司法解释, **第一次起诉离婚, 若被告坚持不同意且无明显过错证据, 法院通常判不准予离婚**。
原告需在判决生效 6 个月后才能再次起诉。

**律师建议**: 第一次起诉前评估胜诉可能性, 必要时先协议离婚。

### 2. 子女抚养原则

- **2 周岁以下**: 一般随母亲 (母方有严重疾病/不宜抚养情形除外)
- **2-8 周岁**: 考虑最有利于子女原则 (原被告条件/子女习惯)
- **8 周岁以上**: 应当尊重子女真实意愿

### 3. 财产分割原则

- 婚前财产归各自
- 婚后共同财产: 一般平分 (适当考虑女方/子女/无过错方利益)
- 约定财产制优先
- 隐藏/转移共同财产: 可少分或不分

### 4. 离婚冷静期 (协议离婚)

协议离婚需经过 30 日冷静期 (《民法典》§1077), 冷静期内任何一方可撤回。
诉讼离婚不受冷静期限制。

### 5. 涉外/涉港澳台离婚

- 一方在国外: 不得协议离婚, 必须诉讼
- 涉港澳台: 适用不同管辖规定
- 华侨/外籍: 适用《民事诉讼法》涉外编
