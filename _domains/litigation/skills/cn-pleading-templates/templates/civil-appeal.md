# 民事上诉状模板

> ⚠️ **律师审阅闸**: 上诉期一般为判决送达之日起 15 日内, 涉外 30 日. 务必用 cn-pleading-appeal-deadline-calc 计算准确截止日.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[上诉人姓名/名称]` | 原审原告或被告 |
| `[被上诉人姓名/名称]` | 对面当事人 |
| `[原审法院全称]` | 作出一审判决的法院 |
| `[案号]` | (2024)京01民初XXXX号 |
| `[原审判决书文号]` | (2024)京01民终XXXX号 |
| `[判决日期]` | 一审判决作出日 |
| `[送达日期]` | 上诉人收到判决日 |
| `[上诉请求]` | 1. 撤销一审判决 2. 改判/发回重审 |
| `[上诉理由]` | 一审判决事实/法律/程序错误 |
| `[落款日期]` | 上诉状递交日 |

## 正文

```markdown

# 民 事 上 诉 状

**[二审法院全称, 通常为原审法院的上一级]**:

## 一、上诉人/被上诉人信息

### 上诉人
- 姓名/名称: [上诉人姓名/名称]
- 身份证号/统一社会信用代码: [...]
- 住所: [...]
- 联系电话: [...]

### 被上诉人
- 姓名/名称: [被上诉人姓名/名称]
- 住所: [...]

(如有多名, 按上述格式继续)

## 二、案由

上诉人因与被上诉人 [案由] 一案, 不服 [原审法院全称] [原审判决书文号]
民事判决 (判决日期: [判决日期]), 特提起上诉。

## 三、上诉请求

1. 请求依法撤销 [原审判决书文号] 民事判决
2. 请求依法改判: [具体改判请求]
3. 一审 / 二审诉讼费由 [被上诉人 / 双方分担] 承担

(可选 4. 发回原审法院重审)

## 四、上诉理由

### (一) 原审判决认定事实错误

[具体指出原审判决在事实认定方面的错误, 列出正确的事实]

例如:
- 原审判决认定 "XX" 事实错误. 实际上 [...]
- 原审判决遗漏了 [关键证据 / 重要事实]
- 原审判决对 [证据 X] 的认定违反证据规则

### (二) 原审判决适用法律错误

[具体指出原审判决适用法律方面的错误]

例如:
1. 原审判决错误适用了《[法条 X]》, 但本案应当适用《[法条 Y]》
2. 原审判决对《[关键法条]》的解释违反立法本意
3. 原审判决遗漏了应当适用的 [司法解释 / 法律]

### (三) 原审判决程序违法 (如有)

例如:
- 原审法院 [违反法定程序, 如管辖错误/应当回避未回避]
- 原审法院 [超期审理 / 剥夺辩论权]
- 原审法院 [对关键证据未质证]

## 五、证据清单 (新证据尤为重要)

| 编号 | 证据名称 | 证明目的 | 是否新证据 |
|------|---------|---------|----------|
| 1 | [新证据 1] | [证明目的] | 是 — 一审后新发现 |
| 2 | [补充证据 2] | [补充一审证据] | 否 |
| ... | ... | ... | ... |

## 六、援引法律

- 《中华人民共和国民事诉讼法》第一百七十一条 (上诉权)
- 《[相关实体法]》第 [X] 条
- 《最高人民法院关于适用《[相关法]》的解释》第 [X] 条

此致

**[二审法院全称]**

上诉人: [上诉人姓名/名称] (签字/盖章)

[落款日期]

```

## 二审改判常见理由

1. **事实认定错误** — 一审认定的事实缺乏证据支持
2. **法律适用错误** — 适用了错误或失效的法条
3. **程序违法** — 严重违反法定程序, 影响实体公正
4. **新证据** — 一审后才发现的证据, 足以推翻原判
5. **遗漏必要共同诉讼人** — 程序违法, 应发回重审
