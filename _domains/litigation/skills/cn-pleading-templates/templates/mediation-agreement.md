# 民事调解协议模板

> ⚠️ **律师审阅闸**: 调解协议经双方签收后具有民事合同效力; 经法院/仲裁委确认后具有强制执行力. 条款务必明确无歧义.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[协议编号]` | (协议类型)字第 XX 号 |
| `[甲方]` | 申请人/原告/债权人 |
| `[乙方]` | 被申请人/被告/债务人 |
| `[纠纷背景]` | 简要叙述 (1-2 段) |
| `[协议条款]` | 1-N 项, 编号清晰 |
| `[履行方式]` | 一次性 / 分期 / 抵销 等 |
| `[违约责任]` | 逾期违约金 / 担保 |
| `[生效条件]` | 双方签字 / 法院确认 / 律师见证 |
| `[管辖]` | 履行地法院 / 仲裁委 |
| `[签字]` | 双方签字/盖章/日期 |

## 调解 vs 判决 vs 和解

| 维度 | 调解协议 | 法院判决 | 当事人自行和解 |
|------|---------|---------|---------------|
| 强制执行力 | 需法院/仲裁委确认 | 自动有 | 无 (需另行起诉) |
| 履行率 | 高 (双方自愿) | 中 (可能上诉/执行难) | 低 |
| 灵活度 | 高 (条款自定义) | 低 (法定判决) | 高 |
| 律师费 | 低 | 中-高 | 低 |
| 适用 | 双方仍合作可能 | 矛盾已激化 | 私下解决 |

## 关键条款模板

### 1. 分期付款条款

```
乙方应自本协议生效之日起 X 日内, 向甲方支付人民币 Y 万元,
具体分期为:
- 第一期: [日期], 金额 Y1 万元
- 第二期: [日期], 金额 Y2 万元
- 第三期: [日期], 金额 Y3 万元
任一期逾期, 视为全部到期, 甲方有权就剩余全部款项申请强制执行。
```

### 2. 担保条款

```
乙方以其名下 [财产/股权/车辆] 作为担保, 如乙方未按期履行,
甲方有权依法处分该担保物并优先受偿。
```

### 3. 保密条款

```
双方对本协议内容承担保密义务, 未经对方书面同意, 不得向第三方披露。
违反保密义务的一方应赔偿对方因此遭受的全部损失。
```

### 4. 解除条款

```
如乙方按本协议第一条全面履行, 甲方不得就 [原纠纷] 再行主张权利。
如乙方任一期违约, 视为本协议未生效, 甲方有权按原纠纷继续追究乙方责任。
```
