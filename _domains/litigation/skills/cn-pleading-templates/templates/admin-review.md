# 行政复议申请书模板

> ⚠️ **律师审阅闸**: 复议前置 (如税务/部分行政处罚) 必须先复议; 其他可选择复议或诉讼. 时效 60 日 (《行政复议法》第二十条).

## 必填字段

| 字段 | 说明 |
|------|------|
| `[复议机关全称]` | 作出具体行政行为的行政机关的上一级 |
| `[申请人]` | 公民/法人/其他组织 |
| `[被申请人]` | 作出具体行政行为的行政机关 |
| `[具体行政行为]` | 处罚决定书/强制措施/不予答复等 |
| `[文号]` | 如: (2024)京朝环保罚字 XX 号 |
| `[作出日期]` | 行政行为作出日 |
| `[收到/知道日期]` | 申请人收到或知道行政行为日 |
| `[复议请求]` | 撤销/变更/确认违法/责令履行 |
| `[复议理由]` | 主要事实不清/证据不足/适用依据错误/违反程序/超越职权/滥用职权 |

## 正文

```markdown

# 行 政 复 议 申 请 书

**[复议机关全称]**:

## 一、申请人信息

(如为自然人)
- 姓名: [申请人姓名]
- 性别: [...]
- 身份证号: [...]
- 住所: [...]
- 联系电话: [...]

(如为法人或其他组织)
- 名称: [单位全称]
- 统一社会信用代码: [...]
- 住所: [...]
- 法定代表人: [...]

## 二、被申请人信息

- 名称: [作出行政行为的行政机关全称]
- 住所: [...]
- 法定代表人: [...]
- 职务: [...]

## 三、复议请求

1. 请求依法撤销被申请人作出的 [具体行政行为名称] ([文号])
2. (或者) 请求依法确认该具体行政行为违法
3. (或者) 请求责令被申请人 [履行某项职责]

## 四、事实与理由

### (一) 案件事实

[按时间顺序叙述行政行为作出的经过 + 申请人不服的理由]

例如:
- [日期]: 申请人 [经营活动/行为]
- [日期]: 被申请人 [作出具体行政行为, 如: 罚款 XX 万元/责令停产停业]
- 行政行为 [文号]
- 申请人认为该行政行为 [违法/不当], 理由如下:

### (二) 复议理由 (五选一或多选)

依据《中华人民共和国行政复议法》第二十八条, 具体理由:

**1. 主要事实不清、证据不足** (第三项第 1 目)
   [指出被申请人认定事实错误, 证据不足的具体内容]

**2. 适用依据错误** (第三项第 2 目)
   [指出被申请人错误适用了 [法条 X], 应当适用 [法条 Y]]

**3. 违反法定程序** (第三项第 3 目)
   [指出被申请人违反 [程序规定 X, 如: 未告知听证权利/未送达/超期]

**4. 超越职权 / 滥用职权** (第三项第 4 目)
   [指出被申请人无权作出该行政行为, 或明显不当]

**5. 具体行政行为明显不当** (第三项第 5 目)
   [指出处罚畸重/违反比例原则等]

### (三) 法律依据

- 《中华人民共和国行政复议法》 第六条 / 第十一条 (复议申请权)
- 《中华人民共和国行政诉讼法》 [第 X 条, 如拟同时提起诉讼]
- 《[相关实体法, 如: 行政处罚法 / 税法 / 环保法]》 第 [X] 条

## 五、证据清单

| 编号 | 证据名称 | 证明目的 |
|------|---------|---------|
| 1 | [行政决定书原件/复印件] | 证明被诉行政行为存在 |
| 2 | [送达回证] | 证明申请人在法定期限内 |
| 3 | [现场笔录/照片/录像] | 反驳被申请人认定的事实 |
| 4 | [相关法律法规文本] | 证明适用依据错误 |
| 5 | [程序违法证据, 如: 听证通知缺失] | 证明程序违法 |
| ... | ... | ... |

此致

**[复议机关全称]**

申请人: [姓名/名称] (签字/盖章)

[落款日期]

```

## 复议前置 vs 复议选择

| 案件类型 | 是否复议前置 |
|---------|------------|
| 纳税争议 (税款/滞纳金) | ✅ 前置, 必须先复议 |
| 自然资源权属确认 | ✅ 前置 |
| 部分海关处罚 | ✅ 前置 |
| 普通行政处罚 | ❌ 可选择复议或直接诉讼 |
| 行政强制 | ❌ 可选择 |
| 不作为 | ❌ 可选择 |
