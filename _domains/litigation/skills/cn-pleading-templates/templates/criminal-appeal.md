# 刑事申诉状模板

> ⚠️ **律师审阅闸**: 申诉与再审申请不同. 申诉是当事人/法定代理人/近亲属向法院/检察院申诉, 不必然启动再审. 申请再审是有专门诉讼请求. 刑事申诉时效 2 年 (《刑事诉讼法》第二百五十二条), 死刑/无期/过期后发现的重大案件不受此限.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[申诉人]` | 被告人/被害人/法定代理人/近亲属 |
| `[被申诉人]` | 原审被告人 (如有) |
| `[原审法院]` | 作出生效判决/裁定的法院 |
| `[生效判决书文号]` | (2024)京01刑初XX号 / (2024)京01刑终XX号 |
| `[原判决/裁定结果]` | 罪名 + 刑期 |
| `[生效日期]` | 判决/裁定生效日 |
| `[申诉请求]` | 撤销原判 / 改判无罪 / 减轻处罚 |
| `[申诉理由]` | 事实/证据/法律/程序 |

## 正文

```markdown

# 刑 事 申 诉 状

**[接受申诉的法院或检察院全称]**:

## 一、申诉人信息

### 申诉人 (被告人/被害人/近亲属)
- 姓名: [申诉人姓名]
- 与原审被告人/被害人关系: [本人 / 父 / 母 / 配偶 / 子女 / 法定代理人]
- 身份证号: [...]
- 住所: [...]
- 联系电话: [...]
- (如为律师代理, 附授权委托书)

### 原审被告人
- 姓名: [原审被告人姓名]
- 罪名: [罪名]
- 原判刑期: [具体刑罚]

### 被申诉人 (如有)
- 姓名/名称: [...]
- 住所: [...]

## 二、原审情况

申诉人对 [原审法院全称] [生效判决书文号] 刑事判决/裁定不服,
该判决/裁定已于 [生效日期] 发生法律效力。

原审判决/裁定:
- 被告人 [姓名] 犯 [罪名]
- 判处 [刑罚, 如: 有期徒刑 X 年]
- (或 死刑 / 无期徒刑 / 缓刑 / 管制 / 罚金 等)

## 三、申诉请求

1. 请求依法撤销 [生效判决书文号] 刑事判决/裁定
2. 请求对本案进行再审, 并依法改判:
   - (或者) 宣告 [申诉人/被告人] 无罪
   - (或者) 减轻处罚 (从重至 [新刑期])
   - (或者) 适用缓刑
   - (或者) 适用减刑/假释

## 四、申诉理由

### (一) 原审判决认定事实确有错误

[具体指出原审认定事实错误的证据和理由]

例如:
1. 原审判决认定 "XX" 事实错误, 实际应为 [...]
2. 原审判决据以定罪的关键证据 [证据 X] 系伪造/变造/来源不合法
3. 原审判决遗漏了 [对申诉人有利的关键证据]
4. 新发现的证据足以推翻原判决

### (二) 原审判决据以定罪量刑的证据不确实、不充分

1. 原审据以定罪的 [关键证据, 如: 被告人供述/证人证言/物证/鉴定意见] 存在重大疑点:
   - [具体疑点 1]
   - [具体疑点 2]
2. 原审据以量刑的情节 [事实 X] 与实际不符
3. (如适用) 原审证据未达到 [罪名] 的证明标准

### (三) 原审判决适用法律确有错误

1. 原审判决错误适用了 [法条 X], 应当适用 [法条 Y]
2. 原审判决对 [法律条文] 的理解违反立法本意/司法解释
3. (如适用) 申诉人的行为不构成犯罪 / 应当从轻/减轻/免除处罚
4. (如适用) 存在 [正当防卫/紧急避险/犯罪未遂/既遂/共同犯罪认定错误等]

### (四) 原审诉讼程序严重违法

1. 原审法院 [违反管辖规定/应当回避未回避]
2. 原审剥夺了 [申诉人的辩护权/质证权/最后陈述权]
3. 原审 [超期羁押/超期审理]
4. 原审 [据以定罪的关键证据未质证]
5. 原审 [合议庭组成不合法]

## 五、新证据清单 (如有)

| 编号 | 证据名称 | 证明目的 | 新发现时间 |
|------|---------|---------|----------|
| 1 | [新证据 1] | 推翻原审认定 [事实 X] | [日期] |
| 2 | [新证据 2] | 证明 [新事实 Y] | [日期] |
| ... | ... | ... | ... |

## 六、法律依据

- 《中华人民共和国刑事诉讼法》第二百五十二条 (申诉权)
- 《最高人民法院关于适用《中华人民共和国刑事诉讼法》的解释》 [相关条款]
- 《中华人民共和国刑法》 第 [X] 条 (实体法依据)

此致

**[接受申诉的法院/检察院全称]**

申诉人: [姓名] (签字)

[落款日期]

```

## 申诉 / 申请再审 / 抗诉 三种途径对比

| 途径 | 受理机关 | 法律依据 | 时效 | 门槛 |
|------|---------|---------|------|------|
| **申诉** (本模板) | 作出生效判决的法院/检察院 | 刑诉法 §252 | 2 年 | 较低 |
| **申请再审** | 作出生效判决的法院/同级法院 | 刑诉法 §253-§255 | 2 年 | 较高 |
| **抗诉** | 检察院 | 刑诉法 §254 | - | 检察建议 |

**建议顺序**: 先申请再审 (门槛高但有效) → 再申诉 (补充) → 最后考虑抗诉 (需检察院支持)

## 死刑/无期徒刑案件的特别时效

依据《刑事诉讼法》第二百五十二条后段:

> **以下案件不受 2 年申诉时效限制**:
> - 被告人可能被判处死刑的案件
> - 被告人已被判处无期徒刑的案件
> - 判决、裁定发生法律效力二年后, 才发现新证据可能影响原判决的

此类案件即使超过 2 年, 仍可申诉。
