# 律师函模板 (催告/通知/警告性质)

> ⚠️ **律师审阅闸**: 律师函不具强制执行力, 但具有 "诉前通知" 的时效中断效力. 措辞需谨慎, 避免诽谤/威胁.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[函件编号]` | 律所内部编号 (如: [2026] XX 律函字第 XX 号) |
| `[致函对象]` | 自然人/单位名称 |
| `[事由]` | 简明扼要 — "关于 XX 合同欠款事宜" |
| `[事实]` | 委托人与致函对象的关系/纠纷事实 |
| `[法律依据]` | 引用的法律条款 |
| `[要求]` | 1. 支付款项 2. 停止侵权 3. 协商解决 等 |
| `[期限]` | 通常 7-15 日 |
| `[后果告知]` | 逾期不回复将采取的法律行动 |
| `[落款]` | 律所名称 + 律师姓名 + 日期 |

## 正文

```markdown

# 律 师 函

**编号: [函件编号]**

**致: [致函对象姓名/单位全称]**

[律所名称] 依法接受 [委托人姓名/名称] (以下简称 "委托人") 的委托,
指派 [律师姓名] 律师就 **[事由]** 相关事宜, 向贵方致函如下:

## 一、事实

根据委托人陈述及提供的证据:

1. [事实 1, 如: 2024 年 X 月 X 日, 委托人与贵方签订《[合同名称]》]
2. [事实 2, 如: 合同约定总价款人民币 XXX 万元, 委托人已按约履行]
3. [事实 3, 如: 贵方至今未支付任何款项, 尚欠 XXX 万元]
4. [其他关键事实]

## 二、法律依据

贵方上述行为:
- 违反了《[合同法/民法典]》第 [X] 条 (合同约定)
- 构成《中华人民共和国民法典》第五百七十七条规定的违约
- 委托人有依法追究贵方违约责任的权利

## 三、我方要求

请贵方在收到本函之日起 **[期限]** 内:

1. 向委托人支付拖欠款项人民币 [金额] 万元
2. (或者) 与委托人协商还款方案
3. (或者) 停止 [侵权行为名称]
4. 就此事与本律师联系: [律师电话 / 邮箱]

## 四、逾期后果

如贵方在上述期限内未予答复或未与本律师联系, 委托人将依法采取以下措施:

1. 向有管辖权的人民法院提起民事诉讼
2. 申请财产保全, 查封/冻结贵方相应财产
3. 依法追究贵方法律责任, 包括但不限于:
   - 全部欠款 + 利息 (按 LPR 计算)
   - 违约金 (合同约定比例)
   - 诉讼费、保全费、律师费等实现债权的费用

本函件不影响委托人对贵方依法享有的其他权利。

特此函告!

[律所名称]

律师: [律师姓名] ([执业证号])

[落款日期]

[律所联系方式: 地址 / 电话 / 邮箱 / 邮编]

---

**抄送: 委托人留存**

```

## 律师函使用注意事项

1. **不要诽谤**: 措辞基于事实, 避免无证据指控
2. **不要威胁**: 不写"将让你坐牢"等刑事恐吓
3. **时效效力**: 律师函可作为时效中断证据 (民法典 195 条)
4. **送达方式**: 优先 EMS + 公证送达, 保留送达凭证
5. **复核事实**: 律师函内容必须经委托人书面核实

## 常见律师函类型

| 类型 | 用途 |
|------|------|
| **催款函** | 催收欠款, 维权第一步 |
| **侵权警告函** | 知识产权/名誉权侵权警告 |
| **解除合同通知函** | 通知对方合同解除 |
| **律师声明函** | 澄清/制止侵权行为 |
| **诉前调解函** | 诉前最后一次和解机会 |
