# 劳动仲裁申请书模板

> ⚠️ **律师审阅闸**: 劳动仲裁必须先于劳动诉讼 (前置程序). 时效 1 年 (《劳动争议调解仲裁法》第二十七条).

## 必填字段

| 字段 | 说明 |
|------|------|
| `[仲裁委全称]` | 劳动合同履行地或用人单位所在地仲裁委 |
| `[申请人]` | 劳动者 (姓名/身份证号/住所/电话) |
| `[被申请人]` | 用人单位 (全称/统一信用代码/住所/法定代表人) |
| `[仲裁请求]` | 1. 支付工资/经济补偿金/赔偿金 2. 补缴社保 3. 继续履行合同... |
| `[事实与理由]` | 入职/离职/工资/加班/社保等关键事实 |
| `[证据清单]` | 劳动合同/工资条/考勤/微信记录等 |

## 正文

```markdown

# 劳 动 仲 裁 申 请 书

**[仲裁委全称]**:

## 一、申请人信息

- 姓名: [申请人姓名]
- 性别: [男/女]
- 出生日期: [YYYY-MM-DD]
- 民族: [...]
- 身份证号: [...]
- 住所: [...]
- 联系电话: [...]

## 二、被申请人信息

- 名称: [用人单位全称]
- 统一社会信用代码: [...]
- 住所: [...]
- 法定代表人: [...]
- 职务: [...]
- 联系电话: [...]

## 三、仲裁请求

1. 请求裁决被申请人支付申请人 [请求 1, 如: 拖欠的 2024 年 1-6 月工资共计人民币 X 万元]
2. 请求裁决被申请人支付申请人 [请求 2, 如: 违法解除劳动合同赔偿金 X 万元]
3. 请求裁决被申请人 [请求 3, 如: 为申请人补缴 2024 年 X 月至 X 月的社会保险]
4. 请求裁决被申请人 [请求 4, 如: 继续履行劳动合同]

## 四、事实与理由

申请人于 [入职日期] 进入被申请人公司, 担任 [职位], 月工资人民币 [X] 元。

[关键事实时序, 例如:]

- [日期 1]: 申请人入职, 双方签订劳动合同
- [日期 2]: 申请人发现被申请人存在 [违法行为, 如: 未足额支付加班费/未依法缴纳社保]
- [日期 3]: 申请人 [与被申请人沟通, 遭到拒绝/被违法解除合同等]
- [日期 4]: 申请人申请劳动仲裁

被申请人的上述行为违反了:
- 《中华人民共和国劳动法》第五十条 (工资应当以货币形式按月支付给劳动者本人)
- 《中华人民共和国劳动合同法》第三十条 / 第四十七条 / 第八十七条等
- 《中华人民共和国社会保险法》第五十八条 (用人单位应当自行申报缴纳社保)

## 五、证据清单

| 编号 | 证据名称 | 证明目的 |
|------|---------|---------|
| 1 | 劳动合同 | 证明劳动关系 + 工资标准 |
| 2 | 工资条 / 银行流水 | 证明实发工资情况 |
| 3 | 考勤记录 / 加班记录 | 证明加班事实 |
| 4 | 解除/终止劳动合同证明 | 证明解除方式 |
| 5 | 微信 / 邮件沟通记录 | 证明 [事实 X] |
| 6 | 社保缴费明细 | 证明社保缴纳情况 |
| ... | ... | ... |

## 六、管辖说明

依据《中华人民共和国劳动争议调解仲裁法》第二十一条,
劳动争议仲裁委员会负责本辖区内的劳动争议。
本案的管辖仲裁委为 [仲裁委全称], 因为:
- 劳动合同履行地位于 [X 市 X 区], 或
- 用人单位 (被申请人) 住所地位于 [X 市 X 区]

此致

**[仲裁委全称]**

申请人: [姓名] (签字)

[落款日期]

```

## 劳动仲裁常见请求类型

| 案由 | 常见仲裁请求 |
|------|------------|
| 拖欠工资 | 支付工资 + 加付赔偿金 (50-100%) |
| 违法解除 | 继续履行 或 赔偿金 (2N) |
| 经济性裁员 | 经济补偿金 (N) |
| 加班费 | 加班费 + 利息 |
| 未签合同 | 二倍工资 (最多 11 个月) |
| 社保 | 补缴 + 滞纳金 |
| 年终奖 | 支付年终奖 |
| 工伤 | 工伤保险待遇 |
