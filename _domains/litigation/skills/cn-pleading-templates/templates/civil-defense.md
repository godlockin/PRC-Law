# 民事答辩状模板

> ⚠️ **律师审阅闸**: 答辩反驳必须基于事实和法律, 不得虚构抗辩理由. 核对证据原件后再确认.

## 必填字段

| 字段 | 说明 |
|------|------|
| `[法院全称]` | 受案法院 |
| `[案号]` | (2024)京01民初XXXX号 |
| `[答辩人姓名/名称]` | 被告身份 |
| `[被答辩人姓名/名称]` | 原告身份 |
| `[答辩请求]` | 1. 驳回全部诉讼请求 2. 诉讼费由原告承担 |
| `[答辩理由 段落]` | 事实反驳 + 法律反驳 |
| `[证据清单]` | 反证证据 |
| `[答辩日期]` | 落款日期 |

## 正文

```markdown

# 民 事 答 辩 状

**[法院全称]**:

就 [被答辩人姓名/名称] 诉 [答辩人姓名/名称] **[案由]** 一案,
[答辩人姓名/名称] 现提出答辩如下:

## 一、答辩请求

1. 请求依法驳回原告 [被答辩人姓名/名称] 的全部诉讼请求
2. 本案诉讼费由原告承担

## 二、答辩理由

### (一) 事实方面

[对原告所述事实的反驳 — 时间/地点/金额/责任认定等关键事实逐项抗辩]

例如:
- 原告主张被告 [违约/欠款/侵权] 与事实不符. 实际情况是 [...]
- 原告所述金额 [XX元] 缺乏证据支持
- 原告对 [关键事实] 的陈述存在 [遗漏/错误/虚构]

### (二) 法律方面

原告的诉讼请求缺乏法律依据:

1. [法条 1] 不适用于本案情形, 因为 [...]
2. [原告引用的法条] 已经被 [新法/司法解释] 取代/废止, 依据 cn-norm-verify 校验
3. 即使原告主张的事实成立, 也未达到 [构成要件 / 责任标准]

### (三) 程序方面 (如有)

- 管辖异议: 本案应由 [正确法院] 管辖
- 诉讼时效: 原告主张已超过 [X/] 年诉讼时效期间
- 主体不适: 原告/被告主体资格存疑

## 三、证据清单

| 编号 | 证据名称 | 证明目的 |
|------|---------|---------|
| 1 | [反证证据 1] | 反驳原告所述 [事实 X] |
| 2 | [反证证据 2] | 证明 [反向事实 Y] |
| ... | ... | ... |

此致

**[法院全称]**

答辩人: [答辩人姓名/名称] (签字/盖章)

[答辩日期]

```

## 抗辩策略要点

1. **先事实, 后法律** — 法院更关注事实认定
2. **抓原告证据漏洞** — 三性审查 (真实性/合法性/关联性)
3. **提反诉考虑** — 如果被告也有诉求, 可单独写反诉状
4. **管辖/时效/主体** — 程序抗辩有时一票否决
5. **保持克制** — 答辩反驳有理有据, 不要情绪化
