# clearance · 商标清查

### 步骤 3: 标识分析与三维度近似判断（中文商标）

**3a. 拆解拟用标识**：文字/图形/字母/数字/三维标志/颜色组合/声音及其组合；提取显著识别部分，区分显著性与描述性要素。

**3b. 中文商标三维度近似判断详解**：

| 维度 | 判断要点 | 示例情形 | 判定倾向 |
|------|---------|---------|---------|
| 字形（外观近似） | 汉字构成、偏旁部首、整体外观是否近似 | 形近字："己/已/巳"、"目/日"、"千/干/于" | 字形近似且易产生混淆 → 判近似 |
| 读音（发音近似） | 读音相同或近似，含音同字不同 | 音同字不同："茗/铭"、"优/悠"、"宏/鸿" | 读音相同或近似 + 含义关联 → 判近似 |
| 含义（语义近似） | 含义相同或近似，或互为翻译关系 | 含义相同："龙/恐龙"、"凤凰/凤"；中外文互译 | 含义近似易误认 → 判近似 |

判断规则：三维度并非孤立，须**综合判断**——任一二维近似且商品类似即可认定混淆可能性；音同字不同或形近字均可能判近似。外文商标按字母构成、发音、含义判断；图形商标按整体视觉近似度判断。

### 步骤 4: 类别交叉检索策略（区分表使用指南）

- 按《类似商品和服务区分表》确定拟注册类别、商品/服务项目及其类似群（45 类，商品 34 类 + 服务 11 类）
- 优先检索**同一类别类似群**的在先商标

- 在 CNIPA 商标数据库 + WIPO Global Brand Database 双库检索在先商标
- 记录检索式与命中数，标注数据库时滞影响

### 步骤 5: 逐项比对与混淆可能性判断

- **相同商标**（标识完全相同 + 同一种/类似商品）→ 高障碍
- **近似商标**：标识近似度（三维度）× 商品/服务类似度 → 综合判断混淆可能性
- 评估在先权利状态：是否有效、是否连续三年未使用（可提撤销）、是否已过异议期

### 步骤 6: 输出报告
- 🔴 高障碍：存在高度近似在先商标，建议改名或专项法律意见
- 🟡 中风险：存在部分冲突或类别边界模糊，需细化检索或复审
- 🟢 低风险：未见明显在先冲突，可推进申请（不代表必然注册）

## 特殊注意事项
- 中文商标近似判断以字形、读音、含义三维度综合认定，音同字不同或形近字均可能判近似
- 检索结果受数据库更新时滞影响，未见冲突不等于无冲突，申请前建议专业代理机构复核
- 相同/近似判断须结合《类似商品和服务区分表》最新版本，类别交叉项易遗漏
- 三维度判断不能孤立看单一维度，须综合标识近似度与商品类似度判断混淆可能性
- 跨类别类似群（交叉检索）是清查漏检的高发区，须按类似群关系扩展检索范围
- 仅作可注册性筛查，不替代商标局审查决定，最终以官方审查结果为准
